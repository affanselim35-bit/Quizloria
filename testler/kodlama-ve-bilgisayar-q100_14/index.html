Sorular ve açıklamalı öğrenme notları

Önce kendini denemek istersen teste yukarıdan başla. Buradaki başlıkları açtığında doğru cevap görünür; bunlar puanlı bir yarışmanın gizli cevapları değildir.

1. HTML'nin temel görevi nedir?
  1. Etkileşim sağlamak
  2. Veritabanı sorgulamak
  3. Görünümü biçimlendirmek
  4. Sayfa yapısını oluşturmak

Doğru cevap: Sayfa yapısını oluşturmak

HTML, başlık ve paragraf gibi belge öğelerinin yapısını ve anlamını belirtir; CSS sunumu biçimlendirir.

2. CSS'nin temel görevi nedir?
  1. Etkileşim sağlamak
  2. Görünümü biçimlendirmek
  3. Veritabanı sorgulamak
  4. Sayfa yapısını oluşturmak

Doğru cevap: Görünümü biçimlendirmek

CSS renk, yazı tipi ve yerleşim gibi sunum özelliklerini düzenler; veri tabanı sorgulama dili değildir.

3. JavaScript'in webde temel görevi nedir?
  1. Veritabanı sorgulamak
  2. Sayfa yapısını oluşturmak
  3. Görünümü biçimlendirmek
  4. Etkileşim sağlamak

Doğru cevap: Etkileşim sağlamak

JavaScript tıklama gibi olaylara yanıt verebilir ve sayfanın davranışını değiştirebilir; yalnızca tarayıcıda çalışmakla sınırlı değildir.

4. SQL genellikle ne için kullanılır?
  1. Veritabanı sorgulamak
  2. Etkileşim sağlamak
  3. Sayfa yapısını oluşturmak
  4. Görünümü biçimlendirmek

Doğru cevap: Veritabanı sorgulamak

SQL ilişkisel veri tabanlarında sorgulama ve veri yönetimi için kullanılan dildir; Git gibi sürüm geçmişi aracı değildir.

5. Git'in temel görevi nedir?
  1. Etkileşim sağlamak
  2. Sayfa yapısını oluşturmak
  3. Görünümü biçimlendirmek
  4. Sürüm kontrolü

Doğru cevap: Sürüm kontrolü

Git değişiklik geçmişini izler ve dallanmayı destekler; uzaktaki bir hizmet olmadan yerel bilgisayarda da çalışabilir.

6. Python'da çıktı vermek için hangi fonksiyon kullanılır?
  1. input()
  2. print()
  3. type()
  4. len()

Doğru cevap: print()

Python'da print() değerleri varsayılan olarak standart çıktıya yazar; input() kullanıcıdan veri okumak içindir.

7. Python'da liste hangi parantezle yazılır?
  1. Köşeli parantez []
  2. Süslü parantez {}
  3. Normal parantez ()
  4. Açılı parantez <>

Doğru cevap: Köşeli parantez []

Python liste gösterimi [1, 2, 3] gibi köşeli parantez kullanır; süslü parantezler sözlük veya küme için kullanılabilir.

8. Python'da fonksiyon hangi anahtar kelimeyle tanımlanır?
  1. return
  2. import
  3. def
  4. class

Doğru cevap: def

def anahtar kelimesi Python'da fonksiyon tanımlar; class sınıf tanımlamak için kullanılır.

9. Python'da yorum satırı hangi işaretle başlar?
  1. --
  2. //
  3. #
  4. /*

Doğru cevap: #

Python'da # işareti, dizge içinde değilse satırın kalanını yorum yapar; // ise bölme işleci olarak farklı anlam taşır.

10. Python'da uzunluk ölçmek için hangi fonksiyon kullanılır?
  1. input()
  2. type()
  3. print()
  4. len()

Doğru cevap: len()

len() dizge veya liste gibi uygun nesnelerin eleman sayısını verir; bütün nesne türleri uzunluk desteklemez.

11. CPU'nun temel görevi nedir?
  1. Geçici bellek olması
  2. Grafik işlemlerini hızlandırmak
  3. Veri depolamak
  4. Komutları işlemek

Doğru cevap: Komutları işlemek

CPU program komutlarını yürütür; kalıcı dosya deposunun görevi SSD gibi aygıtlardadır.

12. RAM'in temel özelliği nedir?
  1. Grafik işlemlerini hızlandırmak
  2. Komutları işlemek
  3. Veri depolamak
  4. Geçici bellek olması

Doğru cevap: Geçici bellek olması

Yaygın RAM türleri geçici çalışma belleğidir; güç kesilince içerikleri korunmaz.

13. SSD'nin temel görevi nedir?
  1. Geçici bellek olması
  2. Grafik işlemlerini hızlandırmak
  3. Komutları işlemek
  4. Veri depolamak

Doğru cevap: Veri depolamak

SSD kalıcı veri depolar ve hareketli disk plakası kullanmaz; RAM ile aynı donanım değildir.

14. GPU'nun temel görevi nedir?
  1. Grafik işlemlerini hızlandırmak
  2. Geçici bellek olması
  3. Komutları işlemek
  4. Veri depolamak

Doğru cevap: Grafik işlemlerini hızlandırmak

GPU çok sayıda benzer işlemi paralel yürüterek grafik işlemlerini hızlandırabilir; hesaplama için de kullanılabilir.

15. PSU'nun görevi nedir?
  1. Geçici bellek olması
  2. Komutları işlemek
  3. Elektrik gücü sağlamak
  4. Veri depolamak

Doğru cevap: Elektrik gücü sağlamak

PSU, şebekeden gelen elektriği bilgisayar bileşenlerinin kullanabileceği uygun gerilimlere dönüştüren güç kaynağıdır.
