Sorular ve açıklamalı öğrenme notları

Önce kendini denemek istersen teste yukarıdan başla. Buradaki başlıkları açtığında doğru cevap görünür; bunlar puanlı bir yarışmanın gizli cevapları değildir.

1. Algoritma kaynak kullanımının asimptotik üst sınırını göstermek için hangisi kullanılır?
  1. Big O
  2. UTF-8
  3. IEEE 754
  4. ASCII

Doğru cevap: Big O

Big O, girdi büyürken kaynak kullanımına ilişkin asimptotik üst sınırı belirtir; tek başına kesin çalışma süresini saniye cinsinden vermez.

2. FIFO ilkesini kullanan veri yapısı hangisidir?
  1. Öncelik kuyruğu
  2. Yığın
  3. Kuyruk
  4. İkili arama ağacı

Doğru cevap: Kuyruk

FIFO ilk giren ilk çıkar ilkesidir; sıranın başındaki öğe önce işlenir. Öncelik kuyruğu eklenme sırasını zorunlu olarak korumaz.

3. LIFO ilkesini kullanan veri yapısı hangisidir?
  1. Bağlı liste kuyruğu
  2. Kuyruk
  3. Hash tablosu
  4. Yığın

Doğru cevap: Yığın

LIFO son giren ilk çıkar ilkesidir; yığına en son eklenen öğe önce çıkarılır.

4. İkili aramanın sıralı dizide zaman karmaşıklığı nedir?
  1. O(n)
  2. O(log n)
  3. O(2ⁿ)
  4. O(n²)

Doğru cevap: O(log n)

İkili arama her adımda arama aralığını yaklaşık yarıya indirir; veri sıralı ve erişim modeli uygun olduğunda adım sayısı logaritmiktir.

5. İyi dağılan hash ve kontrollü doluluk altında hash tablosunun beklenen arama karmaşıklığı nedir?
  1. O(2ⁿ)
  2. O(n log n)
  3. O(1)
  4. O(n²)

Doğru cevap: O(1)

İyi dağılan hash ve kontrollü doluluk altında beklenen arama sabit zamandır; çakışmalar en kötü durumu daha yavaş yapabilir.

6. Bir fonksiyonun kendisini çağırmasına ne denir?
  1. Serileştirme
  2. Bağlama
  3. Derleme
  4. Özyineleme

Doğru cevap: Özyineleme

Özyineleme fonksiyonun doğrudan veya dolaylı olarak kendisini çağırmasıdır; sonlanma koşulu ve ilerleme önemlidir.

7. Veri tabanında benzersiz satır kimliği nedir?
  1. Birincil anahtar
  2. Yabancı anahtar
  3. İndeks adı
  4. Görünüm

Doğru cevap: Birincil anahtar

Birincil anahtar satırı benzersiz tanımlar ve boş olamaz; birden çok sütundan oluşan birleşik anahtar da olabilir.

8. İlişkisel tabloları sorgulayan dil hangisidir?
  1. CSS
  2. HTML
  3. SVG
  4. SQL

Doğru cevap: SQL

SQL ilişkisel veri tabanlarında sorgu ve veri işlemleri için kullanılır; farklı ürünler dilin farklı uzantılarını destekleyebilir.

9. HTTP 404 kodu neyi gösterir?
  1. Kimlik doğrulama gerekli
  2. Başarılı yanıt
  3. Kaynak bulunamadı
  4. Yönlendirme

Doğru cevap: Kaynak bulunamadı

404 istenen kaynağın bulunamadığını belirtir; sunucu hatası olan 500 ile aynı değildir.

10. HTTP 403 kodu neyi gösterir?
  1. Erişim yasak
  2. İstek başarıyla işlendi
  3. Geçici yönlendirme
  4. Kaynak oluşturuldu

Doğru cevap: Erişim yasak

403 sunucunun isteği anladığını ancak yerine getirmeyi reddettiğini belirtir; 401 kimlik doğrulamayla ilgili farklı durumdur.

11. HTTP 500 kodu neyi gösterir?
  1. Kalıcı yönlendirme
  2. Sunucu hatası
  3. İstemci önbellek onayı
  4. Kaynak bulundu

Doğru cevap: Sunucu hatası

500 beklenmeyen bir sunucu hatasını belirtir; kullanıcının sayfayı yanlış yazdığını tek başına göstermez.

12. HTTPS bağlantısını şifreleyen protokol ailesi nedir?
  1. FTP
  2. TLS
  3. DHCP
  4. DNS

Doğru cevap: TLS

HTTPS, HTTP verisini TLS bağlantısı üzerinden iletir. TLS gizlilik ve bütünlük sağlar; uygulamanın bütün davranışlarını güvenilir yapmaz.

13. Alan adını IP adresine çeviren sistem nedir?
  1. DNS
  2. NTP
  3. SMTP
  4. DHCP

Doğru cevap: DNS

DNS alan adları için IP adresi dahil çeşitli kayıtları çözer; her alan adının yalnız tek IP adresi olmak zorunda değildir.

14. Bağlantı yönelimli, sıralı ve güvenilir bayt akışı sağlayan taşıma protokolü hangisidir?
  1. ICMP
  2. TCP
  3. UDP
  4. ARP

Doğru cevap: TCP

TCP bağlantı yönelimli, sıralı ve güvenilir bayt akışı sağlar; istemci-sunucu iletişimindeki tek olası taşıma protokolü değildir.

15. Paketlerin bağlantısız gönderildiği protokol nedir?
  1. UDP
  2. TLS
  3. TCP
  4. SSH

Doğru cevap: UDP

UDP bağlantısız datagram taşır; sıralama ve teslim garantisini kendisi sağlamaz. Uygulamalar üst katmanda ek mekanizmalar kurabilir.
