Sorular ve açıklamalı öğrenme notları

Önce kendini denemek istersen teste yukarıdan başla. Buradaki başlıkları açtığında doğru cevap görünür; bunlar puanlı bir yarışmanın gizli cevapları değildir.

1. HTML temel olarak ne için kullanılır?
  1. Web sayfasının stilini tanımlamak
  2. Web sayfası yapısını oluşturmak
  3. Veritabanı satırlarını sorgulamak
  4. Kodun sürüm geçmişini yönetmek

Doğru cevap: Web sayfası yapısını oluşturmak

HTML belgenin anlamlı yapısını tanımlar; renk ve yerleşim gibi sunum işleri çoğunlukla CSS'e aittir.

2. CSS neyi düzenler?
  1. İşlemcinin komut kümesini
  2. Git dal geçmişini
  3. Sunucudaki SQL sorgularını
  4. Web sayfasının görünümünü

Doğru cevap: Web sayfasının görünümünü

CSS, HTML öğelerinin renk, yazı tipi ve yerleşim gibi görünüm özelliklerini düzenler.

3. JavaScript genellikle ne için kullanılır?
  1. Veritabanının bütün geçmişini saklamak
  2. Belgenin yalnız başlık yapısını tanımlamak
  3. Ağ kablosunun hızını belirlemek
  4. Web sayfasına etkileşim eklemek

Doğru cevap: Web sayfasına etkileşim eklemek

JavaScript tarayıcıdaki olayları ve sayfa davranışlarını yönetebilir; sunucu tarafında da kullanılabilir.

4. Python hangi tür teknolojidir?
  1. Veri değişim biçimi
  2. Stil sayfası dili
  3. Programlama dili
  4. İşaretleme dili

Doğru cevap: Programlama dili

Python genel amaçlı bir programlama dilidir; yalnızca web sitesi oluşturmakla sınırlı değildir.

5. Bir değişkenin amacı nedir?
  1. Yalnız kaynak kodunu derlemek
  2. Yalnız döngüyü sonlandırmak
  3. Yalnız yorum metni eklemek
  4. Veri saklamak

Doğru cevap: Veri saklamak

Değişken, bir değere program içinde adla erişmeyi sağlar. Değerin değişip değişememesi kullanılan dil ve bildirime bağlıdır.

6. Döngü ne işe yarar?
  1. Değerleri otomatik şifrelemek
  2. Bütün hataları otomatik düzeltmek
  3. İşlemleri yalnız bir kez tanımlamak
  4. İşlemleri tekrarlamak

Doğru cevap: İşlemleri tekrarlamak

Döngüler belirli bir koşul veya tekrar sayısına göre işlemleri tekrarlar; her tekrar için aynı kodu elle yazmayı azaltır.

7. Git genellikle ne için kullanılır?
  1. Ses karıştırma
  2. Sürüm kontrolü
  3. Veritabanı sorgulama
  4. Doku düzenleme

Doğru cevap: Sürüm kontrolü

Git dosyaların değişim geçmişini izleyen dağıtık sürüm kontrol sistemidir; GitHub ise Git depolarını barındıran hizmetlerden biridir.

8. Bir boolean değer hangisi olabilir?
  1. 3.14
  2. 42
  3. Merhaba
  4. true

Doğru cevap: true

Boolean mantıksal veri türü doğru ve yanlış durumlarını temsil eder; true bu iki değerden biridir.

9. API kısaltması neyle ilgilidir?
  1. Yalnız kaynak dosyayı sıkıştırmak
  2. Yazılımların iletişim kurması
  3. Yalnız ekran renklerini belirlemek
  4. Yalnız elektrik tüketimini ölçmek

Doğru cevap: Yazılımların iletişim kurması

API, yazılım bileşenlerinin hangi kurallarla iletişim kuracağını tanımlayan arayüzdür; her API internet üzerinden çalışmaz.

10. Bir algoritma nedir?
  1. Yalnız bir ağ kablosu türü
  2. Yalnız bir donanım modeli
  3. Yalnız bir dosya uzantısı
  4. Bir problemi çözmek için adımlar

Doğru cevap: Bir problemi çözmek için adımlar

Algoritma bir sonuca ulaşmak için tanımlanan adımlardır; mutlaka belirli bir programlama dilinde yazılmış olması gerekmez.

11. 404 HTTP durum kodu genellikle neyi gösterir?
  1. İstek başarılı
  2. Yetki verildi
  3. Sayfa bulunamadı
  4. Sunucu taşındı

Doğru cevap: Sayfa bulunamadı

404, istenen kaynağın sunucuda bulunamadığını belirtir. Sunucu hatası olan 500 ile aynı anlama gelmez.

12. Bir dizinin (array) temel amacı nedir?
  1. Yalnız fonksiyondan dönmek
  2. Yalnız koşul sınamak
  3. Yalnız tek sabit sayı tanımlamak
  4. Birden çok değeri tutmak

Doğru cevap: Birden çok değeri tutmak

Dizi birden çok değeri sıralı bir yapıda tutar; elemanlara erişim ve tür kuralları programlama diline göre değişir.
