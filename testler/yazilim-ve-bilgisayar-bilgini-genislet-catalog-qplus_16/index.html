Sorular ve açıklamalı öğrenme notları

Önce kendini denemek istersen teste yukarıdan başla. Buradaki başlıkları açtığında doğru cevap görünür; bunlar puanlı bir yarışmanın gizli cevapları değildir.

1. Git'te değişiklikleri kalıcı kaydetme komutu nedir?
  1. git status
  2. git fetch
  3. commit
  4. git add

Doğru cevap: commit

git commit hazırlanmış değişikliklerin anlık görüntüsünü yerel geçmişe kaydeder; git add yalnızca hazırlama alanına ekler.

2. Git'te dalları birleştirme işlemi nedir?
  1. git clone
  2. git status
  3. git log
  4. merge

Doğru cevap: merge

git merge başka dalın değişikliklerini geçerli dala birleştirir; çakışma varsa çözmek gerekir.

3. CSS'de esnek kutu düzeni hangi özellikle açılır?
  1. position:flex
  2. display:grid
  3. display:flex
  4. float:flex

Doğru cevap: display:flex

display: flex öğeyi esnek kutu kapsayıcısı yapar; doğrudan çocukları flex öğeleri olarak düzenlenir.

4. JavaScript'te değişmez bağ tanımlayan anahtar sözcük nedir?
  1. function
  2. let
  3. const
  4. var

Doğru cevap: const

const bağın yeniden atanmasını engeller; bağlı nesnenin içeriğini kendiliğinden değişmez yapmaz.

5. HTML'de semantik ana içerik etiketi nedir?
  1. main
  2. aside
  3. nav
  4. footer

Doğru cevap: main

main belgenin baskın ana içeriğini belirtir; gezinme bağlantıları için nav gibi başka semantik öğeler vardır.

6. JSON veri biçiminde nesneler hangi işaretle çevrilir?
  1. Köşeli parantez
  2. Normal parantez
  3. Açılı parantez
  4. Süslü parantez

Doğru cevap: Süslü parantez

JSON nesneleri süslü parantezle, diziler köşeli parantezle yazılır; JSON yorum satırlarını desteklemez.

7. Bir sınıftan nesne üretmeye ne denir?
  1. Derleme
  2. Örnekleme
  3. Kalıtım
  4. Serileştirme

Doğru cevap: Örnekleme

Örnekleme, bir sınıfın tanımından bir nesne örneği oluşturma işlemidir; üst sınıftan özellik alma kalıtımdır.

8. OOP'de veriyi ve yöntemleri bir arada tutma nedir?
  1. Özyineleme
  2. Kalıtım
  3. Serileştirme
  4. Kapsülleme

Doğru cevap: Kapsülleme

Kapsülleme durum ve davranışı bir araya getirir, erişimi tanımlı arayüzlerle sınırlandırabilir; yalnızca kodu aynı dosyaya koymak değildir.

9. OOP'de üst sınıftan özellik alma nedir?
  1. Derleme
  2. Kapsülleme
  3. Örnekleme
  4. Kalıtım

Doğru cevap: Kalıtım

Kalıtımda alt sınıf üst sınıfın özellik ve davranışlarını devralabilir; her tasarımda kalıtım kullanmak zorunlu değildir.

10. Aynı arayüzün farklı davranışları desteklemesi nedir?
  1. Kapsülleme
  2. Örnekleme
  3. Çok biçimlilik
  4. Serileştirme

Doğru cevap: Çok biçimlilik

Çok biçimlilik ortak arayüz üzerinden farklı somut davranışların çağrılabilmesidir; nesnelerin aynı iç yapıda olması gerekmez.

11. Bir işlemin ya tamamen ya hiç gerçekleşmemesi hangi ACID özelliğidir?
  1. Kalıcılık
  2. Tutarlılık
  3. Atomiklik
  4. Yalıtım

Doğru cevap: Atomiklik

Atomiklik bir işlemin bütün adımlarının birlikte tamamlanması veya geri alınmasıdır; kalıcılık tamamlanmış verinin korunmasıdır.

12. SQL enjeksiyonuna karşı temel yöntem nedir?
  1. Parolayı SQL'e eklemek
  2. Tüm tırnakları koşulsuz silmek
  3. Dizge birleştirerek SQL üretmek
  4. Parametreli sorgu

Doğru cevap: Parametreli sorgu

Parametreli sorguda veri ile SQL yapısı ayrılır; girdi sorgu komutu olarak yorumlanmaz. Yetki ve diğer güvenlik önlemleri de gereklidir.

13. Bir API'nin kaynak odaklı tasarım yaklaşımı nedir?
  1. FTP
  2. REST
  3. SMTP
  4. CSS

Doğru cevap: REST

REST kaynaklar ve temsilleri çevresinde tanımlanan mimari bir yaklaşımdır; yalnızca JSON döndüren her uç nokta otomatik olarak REST sayılmaz.

14. Birim testleri neyi sınar?
  1. Küçük kod birimlerini
  2. Yalnız gerçek ödeme işlemlerini
  3. Yalnız üretim veritabanını
  4. Yalnız bütün sistemi uçtan uca

Doğru cevap: Küçük kod birimlerini

Birim testleri küçük davranış birimlerini sınar; bütün sistemin bileşenler arası uyumunu entegrasyon testleri ele alır.

15. İki faktörlü doğrulama ne sağlar?
  1. Kullanıcının otomatik yönetici olması
  2. Parolanın herkese açılması
  3. Ek kimlik doğrulama katmanı
  4. Bütün saldırıların kesin engellenmesi

Doğru cevap: Ek kimlik doğrulama katmanı

İki faktör, kimlik doğrulama için farklı türden iki kanıt ister; tek bir parolanın sızmasının etkisini azaltabilir.
