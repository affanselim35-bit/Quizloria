Sorular ve açıklamalı öğrenme notları

Önce kendini denemek istersen teste yukarıdan başla. Buradaki başlıkları açtığında doğru cevap görünür; bunlar puanlı bir yarışmanın gizli cevapları değildir.

1. CPU kısaltması neyi ifade eder?
  1. Ağ arayüz birimi
  2. Merkezi İşlem Birimi
  3. Grafik işlem birimi
  4. Kalıcı depolama birimi

Doğru cevap: Merkezi İşlem Birimi

CPU, komutları işleyen merkezi işlem birimidir; dosyaların kalıcı olarak saklandığı diskle aynı şey değildir.

2. HTML en çok ne için kullanılır?
  1. Sürüm geçmişini birleştirme
  2. Sayfanın görsel stilini tanımlama
  3. Web sayfası yapısını oluşturma
  4. Veritabanı sorgusu yürütme

Doğru cevap: Web sayfası yapısını oluşturma

HTML başlık, paragraf ve bağlantı gibi öğeleri tanımlar. Görünümü ağırlıklı olarak CSS düzenler.

3. Bir web sitesinin adresini açmak için hangisi kullanılır?
  1. Tarayıcı
  2. Elektronik tablo
  3. Dosya sıkıştırıcı
  4. Görsel düzenleyici

Doğru cevap: Tarayıcı

Tarayıcı web adreslerini açıp sayfaları görüntüler; arama motoru ise tarayıcıdan erişilebilen bir arama hizmetidir.

4. RAM'in temel görevi nedir?
  1. Dosyaları güç kesilince de kalıcı saklamak
  2. Ekran piksellerini üretmek
  3. Geçici çalışma belleği sağlamak
  4. Ağ paketlerini yönlendirmek

Doğru cevap: Geçici çalışma belleği sağlamak

RAM çalışan programların verilerini geçici olarak tutar; çoğu RAM türünde elektrik kesildiğinde veriler kaybolur.

5. Hangisi bir işletim sistemidir?
  1. Google Chrome
  2. Microsoft Word
  3. Adobe Photoshop
  4. Windows

Doğru cevap: Windows

Windows bir işletim sistemidir; Word ve Chrome ise işletim sistemi üzerinde çalışan uygulamalardır.

6. İki aşamalı doğrulama neyi artırır?
  1. Oturumların süresiz kalmasını
  2. Hesap güvenliğini
  3. Parolanın herkese görünürlüğünü
  4. Her kullanıcıya yönetici yetkisini

Doğru cevap: Hesap güvenliğini

İki aşamalı doğrulama, parolanın yanında ek bir doğrulama adımı ister. Bu, hesabın ele geçirilmesini zorlaştırır ama her riski ortadan kaldırmaz.

7. USB genellikle ne amaçla kullanılır?
  1. Yalnız alan adı çözme
  2. Veri ve cihaz bağlantısı
  3. Yalnız görüntü sıkıştırma
  4. Yalnız kablosuz yönlendirme

Doğru cevap: Veri ve cihaz bağlantısı

USB, cihazlar arasında veri aktarımı ve bağlantı sağlayan standartlar ailesidir; bazı bağlantılar güç de iletir.

8. Hangisi bir programlama dilidir?
  1. HTML
  2. JSON
  3. Python
  4. CSS

Doğru cevap: Python

Python bir programlama dilidir; HTML işaretleme dili, CSS ise stil sayfası dilidir.

9. SSD'nin temel kullanım amacı nedir?
  1. Veri depolamak
  2. Program komutlarını yürütmek
  3. Geçici çalışma belleği olmak
  4. Ağ adresini çözmek

Doğru cevap: Veri depolamak

SSD, verileri kalıcı olarak saklayan depolama aygıtıdır; RAM gibi yalnızca geçici çalışma alanı değildir.

10. HTTPS, HTTP'ye göre genellikle ne sağlar?
  1. Bağlantının izinsiz kullanıcıya açılmasını
  2. Cihazdaki bütün zararlı yazılımların silinmesini
  3. Sitenin tüm iddialarının doğru olmasını
  4. Şifrelenmiş bağlantı

Doğru cevap: Şifrelenmiş bağlantı

HTTPS bağlantıdaki verileri TLS ile korur. Kilit simgesi sitenin her iddiasının güvenilir olduğunu garanti etmez.

11. E-posta adreslerinde yaygın olarak hangi işaret bulunur?
  1. #
  2. @
  3. %
  4. &

Doğru cevap: @

@ işareti e-posta adresinde yerel kısmı alan adından ayırır: ad@ornek.com gibi.

12. Bir dosyanın .png uzantısı genellikle neyi belirtir?
  1. Görsel dosyası
  2. Ses dosyası
  3. Çalıştırılabilir program
  4. Metin belgesi

Doğru cevap: Görsel dosyası

PNG kayıpsız sıkıştırma ve saydamlık desteği olan bir raster görsel biçimidir; ses veya çalıştırılabilir program biçimi değildir.
